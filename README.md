# Analog

An offline-first Android music player with a warm, vintage hi-fi identity.

## Current foundation
- Kotlin + Jetpack Compose
- Media3 playback service for background playback and system media controls
- Local audio library via Android MediaStore
- Dark analog-inspired library UI with amber and phosphor-green accents

## Build
Open this repository in Android Studio (JDK 17, Android SDK 35), allow Gradle sync, then run the `app` configuration on an Android device.

## Roadmap
1. Full-screen retro spectrum visualizer (FFT) and analog VU meters
2. Albums, artists, folders, playlists, favorites, and queue management
3. Equalizer, bass boost, gapless playback, sleep timer, and lyrics
4. Theme and visualizer customization

Analog is designed for music stored on your device. It does not stream or download music.
